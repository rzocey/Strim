# Strim
AI Slop Warning

Strim is a lightweight, client-side HTML Single-Page Application (SPA) media indexer that aggregates movies, TV shows, and anime using publicly available metadata APIs and embedded iframe players. Built with vanilla HTML, CSS, and modular JavaScript—with no backend required—it also includes an Android WebView wrapper featuring built-in ad-blocking and domain whitelisting.

Demo: [www.sarkoun.cv](https://www.sarkoun.cv)
